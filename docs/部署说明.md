# 家庭物资管理 · 威联通（QNAP）NAS 部署说明

## 一、导入前必读：从「映像」入口导入，不要从「容器」入口

Container Station 3 左侧有两个容易混淆的导入入口，**报"文件格式不受支持 / Invalid File Format"绝大多数是进错了入口**：

| 入口 | 用途 | 能否导入本镜像 |
| --- | --- | --- |
| **「映像 / Images」**（有的版本叫"镜像"） | 导入 `docker save` 导出的**镜像包** | ✅ 必须从这里导入 |
| 「容器 / Containers」 | 导入容器根文件系统（`docker import` 那种平铺文件系统包） | ❌ 在这里选镜像包会提示格式不受支持 |

**正确步骤：**

1. 打开 **Container Station**。
2. 左侧菜单进入 **「映像 / Images」**（不是「容器 / Containers」）。
3. 点 **「导入 / Import」**。
4. 选择下方任一镜像包，等待导入完成；映像列表出现标签 `family-inventory:1.0.1`。
5. 再基于该映像建立容器。

> 如果你之前是在「容器」页面点的导入，这就是报错原因；回到「映像」页面重新导入即可。

## 四、功能清单

- **账号登录 / 首次注册**：打开应用先进入登录页；系统还没有账号时自动切换为注册页，设置用户名与密码即可进入（密码 6–64 位，bcrypt 哈希存储，不落明文）。已有账号后只显示登录页；点击顶栏右侧用户名展开菜单，可进入位置管理、批量导入、批量管理、标签管理、关于（查看版本号），或退出登录。数据接口均需携带登录令牌，未登录访问返回 401。
- **物品详情弹窗**：在网格或列表中点击物品卡片 / 行的任意非按钮区域，弹出详情窗，展示图片、所在位置完整路径、数量、条码 / 编号、标签、备注描述、创建与更新时间；弹窗内可直接跳转「编辑」或查看「二维码」。
- **批量导入物品**：用户菜单「⬆ 批量导入」上传 UTF-8 编码 CSV（列：名称、位置、标签、条码、数量、备注），可先下载模板按列填写；位置填完整路径即可，不存在的层级会自动逐级创建；导入后展示成功 / 失败条数与逐行错误原因。
- **批量删除**：用户菜单「☑ 批量管理」进入选择模式，卡片 / 行出现复选框，可单个勾选或全选，操作栏显示已选数量，确认后一次性删除所选物品（图片一并删除）。
- **二维码标签打印导出**：批量管理中勾选物品后点「▦ 导出所选二维码」，或在位置管理页点「▦ 位置二维码」，生成排版好的标签页（二维码 + 名称 + 位置路径），浏览器内直接打印或另存为 PDF，裁剪后粘贴到物品 / 位置；单个物品 / 位置二维码弹窗内也可「下载图片」保存 PNG。
- **层级位置树**：位置支持多级父子结构，例如 `主卧 → 主卧衣柜 → 第一层 / 第二层 / 抽屉`；用户菜单「位置管理」进入独立页面，以缩进树展示，可展开 / 收起，可在任意节点下添加子位置，页面内布局图缩略图更大，点击可放大查看。
- **按子树筛选**：在主页选择父位置（如主卧）时，自动包含其全部后代位置（主卧衣柜、各层抽屉）下的物品；位置下仍有物品或子位置时不允许删除。
- **位置可输入检索**：新增物品对话框与主页位置筛选框均可直接输入文字，按完整路径（如 `主卧 / 主卧衣柜`）模糊匹配已有位置；表单中输入的新名称会作为根位置自动创建，同级同名判重。
- **条码 / 编号与扫码录入**：每件物品可记录条码或编号；表单点「📷 扫码」调用摄像头识别条码 / 二维码（支持 EAN-13、EAN-8、Code 128、Code 39、UPC、QR 等常见格式），识别结果自动填入；也可手动输入。卡片与列表展示条码，关键字搜索可命中条码。
- **位置布局图**：位置管理页面中每个位置可上传一张布局 / 平面图（PNG / JPG / WebP / GIF，≤10MB），树节点显示较大缩略图，点击放大预览；换图自动清理旧图，删除位置时一并清图。主页按位置筛选后，工具栏出现「🗺️ 查看位置图」按钮，点击即可查看当前筛选位置的布局图；该位置未上传图片时按钮不显示。
- **物品 / 位置二维码**：物品卡片、列表行与位置树均可生成专属二维码，内容为本应用链接；手机扫码后直达对应物品，或自动筛选到对应位置。
- **扫码搜索**：顶部搜索框旁「📷 扫码」可扫描条码或二维码；扫到本应用的物品 / 位置链接时直达对应对象，扫到普通商品条码 / 编号则按关键字检索。
- **物品标签**：每件物品可打多个标签（逗号分隔，如 `数码, 备用, 户外`），卡片上以标签徽章展示；主页可按标签筛选，关键字搜索也会命中标签。新增 / 编辑物品时可点击既有标签快速选中，也可输入新标签；用户菜单「标签管理」可查看各标签件数并直接改名，新名称同步更新到所有相关物品，与既有标签同名时自动合并去重。
- **两种显示方式**：主页右上角可在「缩略图网格」与「列表」两种视图间切换；视图切换按钮与位置、标签筛选框等高对齐。
- **图片上传**：每件物品可配图，支持 PNG / JPG / WebP / GIF，单张 ≤ 10MB；图片落盘 `/data/uploads`，删除物品自动清图，换图自动清理旧图。
- **主页统计与汇总仪表盘**：顶部统计物品总数、位置数量、已配图物品数；卡片展示图片、名称、所属位置路径、数量、标签与备注。顶栏「📊 仪表盘」进入汇总页，含按位置、按标签两组环形饼图，以及各位置件数、物品数量 Top 10 两组横向柱状图；点击图例或柱条返回列表，仅按该维度筛选，同时清除另一维度条件与关键字搜索词（不与既有条件组合），再次点击同一项可取消该维度；「🏠 物品列表」可随时切回主页列表。
- **组合筛选与搜索**：位置、标签、关键字三个条件可叠加；搜索框实时匹配物品名称、备注、位置完整路径（含父级位置，如搜「主卧」可命中「主卧 / 衣柜」下的物品）、条码与标签；每个筛选/搜索框右侧带一键清除按钮（有内容时显示 ×），点击即清空并恢复全部物品。
- **物品维护**：支持新增、编辑、删除物品；编辑时可更换配图、修改位置与标签。

## 五、启动容器

### 方式 1：docker compose（随附 `docker-compose.yml`）

把 `docker-compose.yml` 放到 NAS 一个目录（会在其下创建 `data/` 持久化目录），然后：

```bash
docker compose up -d
```

### 方式 2：纯 docker run

```bash
docker run -d \
  --name family-inventory \
  --restart unless-stopped \
  -p 8080:8080 \
  -v /share/Container/family-inventory/data:/data \
  family-inventory:1.0.1
```

> 若 NAS 上 8080 端口已被占用，把宿主端口改为其他值，例如 `-p 7745:8080`，容器内端口保持 8080 不变。

### SSH 命令行导入（备选）

```bash
# 在「映像」对应的命令行导入；路径按实际上传位置调整
docker load -i /share/Public/family-inventory-1.0.1-amd64.tar

# 确认镜像已载入
docker images | grep family-inventory
```

## 六、首次使用

1. 浏览器访问 `http://<NAS_IP>:8080`（端口按上面的映射调整）。首次打开进入注册页，设置用户名与密码（确认密码一致）后注册并自动登录；之后再打开需用该账号密码登录。
2. 点右上角用户名展开菜单，选 **「位置管理」** 进入独立页面，先建根位置（如：主卧、厨房），再在节点上点「＋子位置」逐级细化（如：主卧 → 主卧衣柜 → 第一层）；点某位置的「🖼️ 布局图」可上传该位置的平面 / 布局照片，缩略图点击可放大查看；新增物品时也可在位置框直接输入新根位置名称，保存后自动创建。
3. 单件物品点 **「＋ 新增物品」**，填写名称、位置、标签（可点选既有标签或输入新标签，逗号分隔）、条码 / 编号（可点「📷 扫码」用摄像头识别，也可手输）、数量、备注，可上传物品图片，保存；物品较多时点用户菜单 **「⬆ 批量导入」**，下载 CSV 模板填好后上传批量录入。
4. 首页用位置框、标签框、搜索框组合筛选；选择父位置会连带其全部子位置；点击物品卡片 / 行可查看完整详情；需要批量整理时在用户菜单点 **「☑ 批量管理」** 勾选物品，可批量删除或导出二维码标签打印；筛选到已上传布局图的位置时，工具栏点「🗺️ 查看位置图」可查看该位置详图；搜索框旁「📷 扫码」可扫条码 / 二维码直接检索；卡片或位置上的「▦ 二维码」可查看 / 下载专属二维码；右上角按钮可在网格与列表视图之间切换；点「📊 仪表盘」可查看按位置、标签的饼图汇总，点「🏠 物品列表」随时返回主页。

## 七、数据备份与维护

- 所有持久化数据都在挂载的 `/data` 目录：`data.json`（账号记录，仅存密码哈希；物品与位置记录）和 `uploads/`（图片）。备份即备份该目录；停止容器后拷贝，或直接备份对应 NAS 共享文件夹。
- 查看日志：`docker logs -f family-inventory`。
- 镜像根文件系统为最小化、不含系统 shell，不支持 `docker exec` 进入交互式终端；日常操作通过 Web 界面与 `docker logs` 完成。
- 重置：删除容器后重新创建即可保留数据；如需彻底清空，删除 `/data` 目录内容后再启动。

## 九、注意事项

- **架构匹配**：本镜像为 `linux/amd64`。若你的威联通是 ARM 处理器机型，此镜像无法运行，需提供机型后另行交叉编译 arm64 版本。
- **访问控制**：本应用已内置账号登录，数据接口需登录后访问；当前为单账号设计，首个注册的账号即管理员，之后不再开放注册，也没有改密 / 找回密码界面。会话令牌保存在服务端内存，容器重启后需重新登录；若忘记密码，停止容器后编辑 `/data/data.json` 删除 `users` 数组即可恢复到首次注册状态。应用仍定位为家庭内网使用，如需外网访问，请通过反向代理（如 NAS 自带的代理 / HTTPS 证书）额外加访问密码或白名单，不要直接裸露到公网。
- **下载后确认扩展名**：从浏览器下载短链文件后，确认文件名结尾是 `.tar` / `.tar.gz`；若被保存成无扩展名或 `.bin`，先手动改回对应扩展名再导入。
- **扫码摄像头的安全上下文**：浏览器调用摄像头（`getUserMedia` / BarcodeDetector）要求 **HTTPS 或 localhost**。若通过普通 `http://<NAS_IP>:8080` 局域网访问，部分浏览器会禁止打开摄像头；此时可直接在条码框手动输入，或给 NAS 配置 HTTPS 反向代理后再使用扫码。扫码使用系统浏览器原生识别，不依赖外部商品数据库，识别到的字符串即作为条码 / 编号保存。
- **二维码链接可达性**：物品 / 位置二维码编码的是生成时浏览器访问的地址（如 `http://192.168.x.x:8080/?item=…`）。用手机扫码时，手机需与 NAS 在同一局域网、且能访问该 IP 与端口；若后续改了端口或改用域名 / HTTPS，建议在新地址下重新打开二维码查看，旧码里的地址不会自动更新。
- **浏览器缓存**：页面为纯静态资源，更新后若显示旧版，强制刷新（Ctrl+F5）或清除站点缓存即可。
- **数据规模**：当前使用 JSON 文件存储，适合家庭场景（数百至数千件物品）；图片以文件形式保存于 `uploads/`，备份时请连同目录一起拷贝。
- **批量导入 CSV**：文件需为 UTF-8 编码（Excel 另存为 CSV 时注意编码，建议先用页面模板下载再填写）；列顺序为名称、位置、标签、条码、数量、备注，名称为空的行会自动跳过；位置路径不存在时会自动逐级创建对应层级。
- **二维码标签打印**：标签页通过浏览器打印功能输出，可选「另存为 PDF」；打印前在预览中确认纸张尺寸与排列（默认两列）。二维码内链接为局域网地址，手机需与 NAS 同网可达。
